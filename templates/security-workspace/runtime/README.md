# 让目标真正运行起来

本目录服务于被研究项目。agent 自身的生成配置在 ../.agent/，会话记录在 ../runs/。

- environment.md：软件、硬件、系统、身份及网络依赖，缺失项与环境方案。
- build.md：确定源码版本、工具链、构建参数、产物及构建结果。
- run.md：部署、启动、最小功能验证、观测方法及停止/恢复步骤。
- configs/：可复查的配置、内核选项、产品开关或设备拓扑。
- scripts/：可复用的环境、构建和启动辅助脚本，标明工作目录与影响。
- artifacts/：镜像、二进制等实际产物，记录来源、版本和摘要；可按需增加子目录。

按项目选择容器、虚拟机、模拟器、开发板或真实设备。内核、硬件及跨设备行为是否能在替代环境研究，需要单独说明；容器启动不等于目标内核或设备能力已运行。

区分“上游文档给出命令”“构建完成”“启动成功”和“实际用例经过目标模块”，每步留下真实结果。未知与阻塞项保留为研究问题；没有运行不要填成功。源码 checkout 保持锁定，构建优先使用独立输出目录；确需改动时保留补丁和源码来源，避免悄悄改变研究基线。
