# 可复用安全知识

- `mechanisms/`：保护目标、实现、启用条件、覆盖和失效边界。
- `attack-surface/`：输入可控性、入口、信任边界和攻击条件。
- `history/`：从历史漏洞、修复、版本变化与对标中提炼的共性知识；完整案例关联 vulnerabilities/、exploits/。
- `questions/`：尚未确认的问题、相互矛盾的证据和待专家回答的事项。

条目至少保留：稳定 ID、结论状态、涉及的 source ID + SHA + 路径/符号、适用构建/部署条件、支持证据与反证、相关知识 ID、最近复查及订正来源。证据路径相对于登记的源码根目录，不以本机绝对路径作为唯一定位方式。

研究过程放在 research/，运行原始记录放在 runs/。专家订正保留在 interactions/corrections/，并复查依赖该前提的知识；新版本不能直接覆盖旧结论的适用范围。当前仅约定 Markdown 记录方式，没有自动建索引或订正传播引擎。

资料原文放 docs/，目标环境与启用配置关联 runtime/，实际实验依据关联 experiments/。知识分类允许扩展，不要求将所有安全认识强行归入这四个目录。
