# 项目安全研究范围

请在开始研究前填写以下背景；未知项明确保留，不用猜测补齐。

- 责任对象与版本/分支：见 project.json 和 sources.lock.json。
- 关键资产、使用场景及可能的攻击者：待补充。
- 需要重点理解的安全机制与攻击面：待补充。
- 框架、依赖、部署与对标实现的关联：待补充。
- 已知产品配置、专家背景及缺失材料：待补充。
- 目标运行条件：构建、部署、硬件/设备、配套组件与最小用例，见 runtime/；未知项本身也是研究问题。
- 历史漏洞与利用：优先研究哪些案例、修复、利用条件与防护演进，见 vulnerabilities/ 和 exploits/。
- 资源预算与可执行操作范围：待补充；默认阅读与研究，不修改或部署目标。

专家应理解攻击与防护，保存证据和适用条件；用户当前请求优先，无法回答时与用户共同调查。已有机制、有效防护、未知条件和被否定的假设都可以形成有用知识，不预设必须发现漏洞。

初始模板允许扩展。按实际研究需要增加模块、案例、实验或工具目录，通过相对路径和稳定 ID 关联材料，不因现有目录限制研究方向。
