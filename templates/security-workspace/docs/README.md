# 项目与外部文档

放项目架构、API、协议、设计、安全机制、部署说明及外部对标资料。源码仓库内已有的文档优先按 source ID + SHA + 路径引用；额外材料可直接放这里，由研究需要决定是否增加子目录。

每项保留标题、来源/URL、发布日期或版本、获取日期和适用范围，区分原始材料与研究者解读。关于本项目的经过核查的结论放入 knowledge/；历史漏洞及利用的完整研究分别放入 vulnerabilities/ 和 exploits/。

外部项目源码登记为 role 为 reference 的 source，放入 sources/ 并锁定 SHA。资料中的凭证和本机绝对路径不能成为重建研究环境的唯一依赖。
